Symbols and Notations

𝔸

Universe of identifiers / atomic names (catalog names, labels, property keys, column names).

𝕃 ⊆ 𝔸

Universe of label names.

𝕂 ⊆ 𝔸

Universe of property keys (property names).

𝕀

Universe of globally unique graph-element identifiers.

𝕋

Universe of types (static, dynamic, and base types).

𝕍

Universe of material values together with the null value.

null

Distinguished null value NULL.

ℕ

Natural numbers.

∞

Infinity (used for implementation-defined maxima and unbounded path-pattern or RPE repetition).

ℤ>0

Positive integers.

X∗

Set of finite sequences over X, including the empty sequence.

P(X)

Powerset of X.

M(X)

Bag/multiset of elements from X (multiplicity function over X).

Mfin(X)

Finite bag/multiset over X.

⇀

Partial function / partial map.

↦

Mapping constructor (e.g., k↦w).

≜

Definitional equality.

⟦⋅⟧

Denotation / semantic evaluation function.

⊢

Typing / judgment turnstile.

⊧

Satisfaction relation.

⊑

Subtype relation.

Ξ

Static type environment.

G

A (GQL) property graph.

V ⊆ 𝕀

Finite set of node identifiers.

E ⊆ 𝕀

Finite set of edge identifiers, disjoint from V (multigraph permitted).

λV : V →P(𝕃)

Node label map.

λE : E →P(𝕃)

Edge label map.

ρV : V → (𝕂 ⇀ 𝕍)

Node property map.

ρE : E → (𝕂 ⇀ 𝕍)

Edge property map.

src,dst : E → V

Edge endpoint functions; for an undirected edge their order is representational only.

→, ↔

Directed / undirected edge markers.

dir : E →{→,↔}

Edge directedness (directed/undirected).

ℝcat

Syntactically well-formed catalog object references of the GQL grammar.

ℚ

Globally resolved references to catalog objects.

Catalog

Abstract carrier of well-formed hierarchical GQL-catalogs.

C

Catalog (logical collection of named GQL objects).

X

Active context (catalog + working schema + working graph site).

WSR

Working schema reference (default parent for relative catalog-object references).

WG

Working graph site, occupied by a graph reference value whose referent is the working graph.

ℜ

Resolution environment (used by typing judgments).

Loc

Local map of parameters and binding variables used while typing expressions; catalog procedure references use catalog resolution.

resolveS(X,r)

Resolution of syntactic catalog reference r ∈ ℝcat to a globally resolved reference of sort S.

BT

Domain of descriptor-bearing binding tables.

BindingTables : ℚ ⇀ BT

Derived catalog projection from resolved binding-table references to binding-table objects.

SCX

Session context containing the session authorization identifier, principal, time zone, session schema and graph, parameters, list behavior, transaction and request context, and termination flag.

ListBeh

Session list-behavior policy for offset/ordinal indexing, negative indices, and out-of-range behavior; it does not govern list unwinding.

T,BT ∈BT

Binding-table objects.

BTunit

Unit binding table containing one empty record; distinct from an empty binding table.

τrec

Record type of a binding table.

fields(τrec)

Declared field-name set of record type τrec.

Recτrec

Set of records inhabiting record type τrec.

T = ⟨τrec,B,ord,pcs⟩

Binding table represented by its record type, finite record multiset, ordering component, and preferred column-name sequence.

B ∈Mfin(Recτrec)

Underlying finite multiset of record occurrences.

supp(B)

Support of bag B: the set of elements with positive multiplicity.

1[P]

Indicator of proposition P: 1 if P holds and 0 otherwise.

ord

Either the unordered marker or an ordering of the record occurrences of B.

pcs

Preferred column-name sequence: not set or a permutation of the table’s column names.

bag(T) = ⟨τrec,B⟩

Order-insensitive bag projection; it is not the complete binding-table object.

cols(T)

Column set of binding table T.

Cnew

Newly introduced columns (e.g., by a pattern).

PPat,GPat,GPBT

Sets of well-formed path patterns, graph patterns, and graph pattern binding tables.

Γ ∈GPat

Graph pattern, including an optional WHERE clause but not a YIELD clause.

Δgpbt ∈GPBT

Graph pattern binding table: a graph pattern with an explicit or implicit YIELD clause; the subscript distinguishes it from an update delta.

vars(Γ),varsexp(Γ)

Declared and exposed graph-pattern variables, including non-value subpath markers.

varsbind(Γ),varsexpbind(Γ)

All and exposed value-bearing node, edge, and path variables.

Dexpo,Dref

Exposure degree; and reference degree, which is undefined for non-referenceable subpath variables.

bind(h)

Binding extracted from match h and restricted to variables exported by the pattern.

GPBTΔgpbt(T)

Graph-pattern binding-table operator for graph pattern binding table Δgpbt.

MatchStmt

Abstract domain of match statements.

MatchOp,MatchBlock

Abstract domains of match operators and match blocks.

Q∈MatchBlock

Match-block metavariable, distinguished from bags B used by the binding-table algebra.

⟦Match(Δgpbt)⟧match

Denotation of MATCH as a binding-table transformer.

σφ,πX

Selection and projection operators.

⋊⋉

Bag natural join.

⊎

Bag union, adding record multiplicities.

μ ∼ ν,μ ⊔ ν

Compatibility and merge of record mappings.

B1 ⋊⋉ 𝜃B2

Guarded bag join: natural join followed by filtering with guard 𝜃.

⊲𝜃

Left outer join with guard 𝜃.

OptExpandF(T)

Per-record optional expansion of T by correlated binding-table transformer F.

OutF(μ)

New-column output of correlated transformer F for one incoming record occurrence μ.

unnestn:L(T)

FOR/list-unnesting operator, binding n to each list element occurrence in field L.

hdr(B)

Variables in the declared record type of bag-valued binding-table representation B.

πL,⊖,padR

Left-variable projection, bag difference on left projections, and null-padding of right-only variables.

E

Static environment for variables, parameters, functions, and relevant catalog objects.

Dyn = (G,μo)

Dynamic subquery environment: current graph and current outer-row mapping.

WALK

Path mode: walk (default).

TRAIL

Path mode: trail.

ACYCLIC

Path mode: acyclic path.

SIMPLE

Path mode: simple path.

M,mode,pm

Generic path-mode parameters.

Path(G)

Set of finite graph paths in G, represented by alternating node/edge sequences.

PathVal

Carrier of material GQL path values, which encapsulate path-element reference lists.

w ∈Path(G)

Graph path or RPE witness.

p ∈PathVal ∪{null}

Material or null path value.

okM(w)

Predicate that graph path w satisfies path mode M.

head(w),tail(w)

First- and last-node accessors for a graph path or RPE witness w.

len(w)

Edge-step length of a graph path or RPE witness w.

PEL(p),len(p)

Path-element list and edge length of path value p.

nodes(p),edges(p)

Node- and edge-list accessors for a path value.

head(p),tail(p)

First- and last-node accessors for a path value.

p ∘ q

Concatenation of path values whose boundary node references have the same referent.

ΣL

Finite alphabet of edge-label names used by the auxiliary RPE calculus.

r,R

Regular path expressions.

𝜀

Auxiliary zero-edge regular path expression.

δ,Sδ

Step predicate and graph-induced ternary step relation.

ψ : Path(G) →{⊤ ⁡,⊥}

Boolean path predicate used to guard an auxiliary regular path expression.

⟦r⟧Gmode

Bag denotation of r over graph G under the selected path mode.

∪ms, ∪set

Multiset and set alternation of regular path expressions.

⋊⋉ ⋈

Bag join on a shared endpoint with path-witness concatenation.

Der(R,pm)

Successful auxiliary derivation trees for R under pm.

χsp(d), ≡sp

Subpath-marker trace of derivation d, and equality modulo the same endpoint/path/marker trace.

Cand(R,pm)

Candidate set obtained by quotienting successful derivations while retaining multiset-alternation marker distinctions.

Πu,v(Cand(R,pm))

Endpoint-partition subset of Cand(R,pm) for fixed endpoints u,v ∈ V .

s

Selective path-search selector; κ is reserved for GQLSTATUS codes.

SPSPs(⋅)

Selective path-search prefix operator with selector s.

ALLPATHS

Non-selective path-search prefix: return all paths; it is not an SPSP.

ANYNPATHS

SPSP form: return any N paths.

SHORTESTNPATHS

SPSP form: return N shortest paths.

SHORTESTNGROUPS

SPSP form: return N shortest groups (partition-wise).

Ω

Abstract store state used by expression and query evaluation.

ηg,ηr

Global and row environments.

⇝⊆ 𝕋 × 𝕋

Partial implicit-cast relation.

⟨Ω,ηg,ηr⟩⊢ E ⇓ u

Expression-evaluation judgment, producing a value or error.

Var

Universe of variables used by expression and graph-pattern semantics.

μ : Var ⇀ 𝕍

Partial variable binding.

⟦ϕ⟧G,μtv

Three-valued denotation of predicate ϕ.

⊤ ⁡

True.

⊥

False.

U

Unknown (Kleene 3-valued logic).

𝔹3 = {⊤ ⁡,⊥,U}

Three-valued Boolean domain (true/false/unknown).

≼, ≺

Applicable weak order on comparable values and its strict part.

≈nd

Recursive GQL not-distinct relation used by grouping and duplicate treatment.

K = ⟨k1,… ⁡,ks⟩

Ordered sequence of grouping keys; ⟨⟩ denotes global aggregation.

κK(r)

Grouping-key tuple extracted from record r in the order fixed by K.

(Bi)i∈I

Pairwise disjoint group subbags induced by not-distinct grouping-key tuples.

Bi ⊑bagB

Subbag relation: every record multiplicity in Bi is at most its multiplicity in B.

F

Aggregator mapping a finite input bag to one aggregate result.

γg→;h→(B)

Combined grouping and grouped-projection operator.

Enumimpl(B)

Implementation-dependent enumeration of an unordered bag’s record occurrences.

ORDERBYo→(B)

OFFSETo(S)

Sequence slicing by offset o.

LIMITℓ(S)

Sequence slicing by limit ℓ.

Property value types supported by the implementation’s conformance claim.

Selected scalar and collection fragments of 𝕋prop.
